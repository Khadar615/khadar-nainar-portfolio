# Khadar Nainar Portfolio

A responsive personal portfolio website showcasing my education, experience, technical skills, certifications, projects, and contact information.

## Features

- Responsive design for desktop, tablet, and mobile
- Hamburger navigation menu
- About section
- Education and experience timeline
- Technical skills section
- Certificate carousel
- Project showcase
- Contact form
- Social media links
- Resume download link
- Smooth scrolling and scroll-based animations

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Formspree for contact form submissions
